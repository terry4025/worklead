# 자동 연결 복구와 전국 발견 개선 진행 (2026-10-27)

> 2026-10-28 설치 판정: 연결 복구 확장 0.6.1만 설치 파일에 반영했다. 아래 M4 분류 수정은 추가 부정 표현의 자동 지원 오탐이 발견되어 운영 설치에서 제외했다. 해당 규칙의 자동 테스트 통과 기록은 설치 증거가 아니다. 현재 설치 백엔드는 `03f8ed0` 기준이다. [최신 상태](STATUS.md)를 따른다.

## 구현 범위

- 확장 0.6.1은 저장된 연결의 `ready` 표시만 믿지 않고 전용 탭, 현재 계정 및 Worklead 응답을 확인한다. 살아 있는 연결의 작업 감시를 복구하고, 끊긴 연결은 기존 허가로 재연결한다. 자동 지원의 기존 제출 확인 기록과 메시지 감시의 순번·본문 표시 동의는 유지한다. 최초 허가가 없는 상태의 자동 연결은 구현하지 않았다.
- 당근 어댑터 0.8.3은 활성 검색 범위 안에서 앱스토어 등록, 스프레드시트 연동, React 화면 수정, 서버 배포 요청의 명시적인 제목을 보완한다. 웹사이트의 앱 패키징과 기존 앱의 스토어 등록 의뢰를 소프트웨어 업무로 분류한다. 50점 기준, 일일 예산과 상세 요청 한도는 바꾸지 않았다.
- 기존에 분석된 저장 공고는 새 규칙으로 자동 일괄 재분석하지 않는다. 이후 새로 분석하거나 재분석한 공고부터 새 분류가 적용된다.

## 발견한 운영 상태

## 검증 한계와 후속 작업

50건의 합성 표본에서 본문·50점 분류는 구매 30개와 비대상 20개를 모두 구분했다. 제목에 단서가 있는 구매 28개는 선별했고, 본문에만 단서가 있는 2개는 제목만으로 찾을 수 없었다. 비구매 13개는 제목에서 함께 선별됐으나 본문 분류에서 제외됐다. 이 수치는 실사이트 전체 정밀도·재현율이 아니다.
