# 화면 설계

## 방향

**조용한 검토 도구.** 판단에 필요한 사실을 정렬된 열로 비교하고, 근거는 한 번 펼치면 원문 위치까지 보이게 한다.

- 중립 회색 바탕 + 흰 작업면 + 잉크 블루 강조(선택·포커스·주요 동작에만).
- 글꼴: Pretendard(동봉, 오프라인) → 맑은 고딕 폴백. 기본 14–15px, 숫자는 고정폭 숫자(tabular-nums).
- 상태는 **기호 모양 + 색 + 글자**: ● 확인됨/정상 · ◐ 추정·주의 · ◌ 미확인 · ◆ 문제 · ⊘ 마감·해당 없음. 색만으로 구분하지 않는다.
- 과도한 카드·차트·배지·애니메이션 없음. 문제 상태는 숨기지 않고 상단 한 줄로 알린다.

## 구성

```
┌ 상단: Worklead [데모 데이터 배지] · 전국 목표 vs 이번 주기 확인 범위 / 실행 진행 · 실시간 연결 · 수집 · 설정 ┐
├ 알림 줄: 정지·부분 수집·권한 대기·AI 실패·연결 문제 (있을 때만)                                          ┤
├ 보기: 검토 · 관심 · 진행 중 · 제외 · 전체(건수)   필터: 검색 · 사이트 · 업무 · 재택 · 모집 · 유형 · 정렬      ┤
├ 목록 (추천 / 확인 필요 구획)                    │ 상세                                                  ┤
│ 점수 │ 제목 + 판단 이유 │ 유형 │ 업무 │ 재택 │ 보수 │ 모집 │ 제목 · 원문 열기 · 관심 · 제외 · 재확인 · 진행 상태  │
│                                                │ 판단(추천 이유, 점수 구성) → 조건과 근거 → 확인할 점 │
│                                                │ → 수익성(추정) → 원문(근거 강조) → 내 기록 → 초안 → 계약·수금 │
└──────────────────────────────────────────────────────────────────────────────────────────────────┘
```

- 목록 폭에 따라 열 구성이 바뀐다 (container query): 넓음 7열 / 보통 5열(유형·업무는 이유 줄 앞에) / 좁음 1열 + 요약 줄.
- 창 폭 1100px 미만이면 상세는 목록 위에 겹쳐 열린다 (Esc 로 닫기).
- 목록·상세 경계는 끌거나 키보드(←/→)로 조절, 값은 이 PC 에 저장.
- Windows 배율(125·150%)은 WebView2 가 처리하고, 설정의 글자 크기(보통·크게·아주 크게)로 추가 조절한다.

## 판단을 빠르게 하는 장치

- 기본 보기 "검토"는 추천과 확인 필요를 한 목록에서 구획으로 비교한다.
- 넓은 창에서는 첫 리드를 자동 선택해 바로 상세를 보여준다.
- 제외(X)하면 다음 리드로 넘어가고, 행은 그 자리에 흐리게 남아 U 로 되돌릴 수 있다. 목록은 읽는 동안 순서가 바뀌지 않는다.
- 새 리드·수집 결과는 배너로 알리고 사용자가 "목록에 반영"(F5)을 누를 때 갱신한다.
- 조건마다 "근거 N" 을 펼치면 인용·근거 유형(원문 명시/추정/내가 확인)과 "원문에서 보기"(해당 구간 강조)가 나온다.

## 정직한 표기

- 예산 없음 → "예산 미기재"(기울임), 금액 협의 → "금액 협의". 0원으로 쓰지 않는다.
- 부정확한 날짜 → "9월 23일경 (원문 '3일 전')". 게시일이 없으면 "게시 미확인"과 최초 발견일을 따로 보인다.
- 접근 차단 → "◆ 접근 차단 · 마지막 상태 모집 중" (마감으로 바꾸지 않음).
- 우선순위 옆에 "규칙 점수, 수주 확률 아님", 미평가 요소 수를 함께 표시.
- 수익성은 "추정 · 세후 순이익 아님", 예산이 없으면 "가설"로 구분.
- 전국: "전국 목표 · 이번 주기 34/51 · 시·도 17/17 (목록 미검증)", 시장 포괄률은 "알 수 없음".

## 키보드

↑↓/J K 이동 · Enter 상세 · Esc 닫기 · O 원문 · S 관심 · X 제외 · U 되돌리기 · R 재확인 · M 메모 · / 검색 · 1–5 보기 · F5 새로고침 · C 수집 · , 설정 · ? 도움말. 입력칸에서는 동작하지 않는다. 목록은 listbox(aria-activedescendant), 보기는 tablist, 대화상자는 네이티브 dialog.

## 데모

`?mode=demo` 또는 브라우저 기본값. 상단 배지에서 시나리오(정상·부분 수집·접근 차단·AI 실패·빈 결과·첫 실행·연결 실패)를 바꿔 모든 상태 화면을 확인할 수 있다. 데모 데이터는 합성이며 운영 데이터·성과와 섞이지 않는다.
