# 설정 없이 등록하는 당근 자동 지원

2026-11-02 구현. 자동 지원의 기본 연결을 앱이 관리하는 시스템 Edge 전용 창으로 변경했다. Chrome 확장 설치·권한 설정·연결코드 복사/붙여넣기를 기본 흐름에서 제거했다.

## 사용 동작

- 현재 설치처럼 자동 지원을 이미 켰지만 최초 연결이 끝나지 않은 경우, 업데이트 후 앱 실행 시 기존 50점/하루 20건 설정으로 전용 창 연결을 자동 등록한다.
- 앱이 전용 창과 저장된 로그인 세션을 관리한다. 로그인이 만료되거나 전용 프로필을 처음 만드는 경우 로그인만 직접 완료해야 한다. 로그인 완료는 앱이 주기적으로 확인하므로 추가 연결 버튼이나 코드 입력이 필요 없다.
- 등록 후에는 앱을 다시 켜면 자동으로 재개한다. 사용자가 누른 중지·연결 해제와 계정/자기소개 변경에 따른 중지는 유지한다.
- 신규 설치는 사용자가 ‘설정 없이 자동 지원 시작’을 누르기 전까지 등록하지 않는다. 화면에 들어왔다는 이유만으로 제출을 시작하지 않는다.
- 수동 Chrome 확장 연결은 접힌 고급 영역에서 계속 사용할 수 있다.

## 실행 경계

기존 Worklead 전용 `%LOCALAPPDATA%/Worklead/jobs-browser-profile/Default`가 정상 디렉터리이면 해당 로그인 세션을 그대로 사용한다. 기존 세션이 없으면 `jobs-auto-browser-profile`을 사용한다. 프로필 선택은 읽기만 하며 개인 Chrome 프로필·쿠키를 복사하지 않는다. 메시지 감시와 자동 지원은 프로세스 내부 및 OS 파일 잠금으로 같은 프로필의 동시 사용을 막는다. 심볼릭 링크·junction·reparse 경로는 사용하지 않는다.

기존 자동 지원의 점수·자격·모집 상태·하루 상한·기지원 확인·질문 보류·계정/기본 자기소개 바인딩·제출 journal을 그대로 사용한다. DOM 검사와 버튼 동작은 별도 CDP isolated world에서 실행한다. 제출 직전에 DB 복원 gate와 자동 지원 lock을 함께 확보해 사용자 중지·복원이 제출 허가와 클릭 사이에 끼지 않게 한다.

연결 전에 오래된 적격 원문을 준비할 수 있도록 앱의 처리 루프가 30초마다 원문 재확인 예약을 점검한다. 실제 수집은 기존 수집 큐·요청 예산을 거친다. 원문 재확인 예약은 최대 60초에 1건이며 후보는 100건 단위로 순환한다. 이 준비 루프는 지원 claim이나 제출 허가를 만들지 않는다.

전용 창 실행 실패/닫힘은 같은 프로필로 5·15·60초 뒤 복구하며, 이후에도 2분부터 최대 15분까지 지연을 늘려 자동 복구를 이어간다. 정상 연결이 60초 유지되면 복구 실패 횟수를 초기화해 이전 장애가 계속 누적되지 않게 한다. 사이트의 접근 제한은 자동 우회하지 않는다. 제출 결과가 불확실하면 재제출하지 않고 5·15·30초 간격 최대 3회 공식 완료 표시만 읽어 기존 receipt와 대조한다. 추가 수집·장기 운영 개선은 `UNATTENDED_IMPROVEMENTS_20261102.md`에 기록했다.

## 구현 위치

- `jobs/managed_setup.py`: 등록 API, 기존 미연결 설치 이전, 사용자 중지 보존, 재시작 복구.
- `jobs/managed_auto.py`: 브라우저 수명주기, 기존 지원 허가 경로 호출, 결과 대조.
- `jobs/managed_browser.py`: 앱 전용 시스템 Edge와 CDP isolated world.
- `jobs/auto_apply.py:prepare_candidates()`: 브라우저 연결 전 원문 준비.
- `POST /v1/jobs/auto-apply/setup`: 인증된 로컬 등록. 비밀값/연결코드를 반환하지 않는다.

## 검증 및 배포 기록

관련 백엔드 회귀 검사, UI 330개, 확장 108개, 시스템 Edge의 합성 HTML 검사 및 합성 지원 1회 완료/중복 방지를 확인했다. 실제 사이트에 대한 지원 완료는 이 검사 결과로 주장하지 않는다.

출고 소스는 10월 28일 설치본의 백엔드를 기준으로 이번 연결/자동등록 변경만 반영했다. 기존 작업 중인 M4 분류·수집기 변경은 제외했다. 빌드·전체 회귀·설치·데이터 보존·실행 상태의 실제 결과는 `artifacts/install-20261102-managed/`에 기록한다.
