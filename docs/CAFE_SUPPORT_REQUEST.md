# 당근 고객센터 확인용 초안 (2026-10-12)

상태: **미발송 초안 보관 — 사용자가 “문의 없이 진행해줘”로 발송을 취소함**. 이전 발송 승인을 현재 유효한 승인으로 사용하지 않는다. 계정·전화번호·인증정보·개인정보를 포함하지 않았다. 이 초안은 기능 지원·자동화 사용 동의가 아니다.

확인한 공식 문의 경로: [당근 고객센터 문의하기](https://cs.kr.karrotmarket.com/wv/feedbacks/new?type=karrot) → 커뮤니티 → 온라인카페. 전용 Edge에서 온라인카페를 누르면 `로그인이 필요해요 / 당근 앱으로 열기` QR 안내가 표시됐다. 실제 문의 입력 필드는 없었다. 카페 웹 로그인만으로 문의 작성 양식에 접근하지 못했다. QR 이미지가 고정 자산이라는 사실만으로 스캔 후 웹 인증이 완료된다고 추론하지 않는다. 이전 발송 승인 후 보이는 전용 Edge에 공식 QR을 열었으나, 사용자가 문의를 취소하여 창을 정상 종료했다. 추가 인증·문의 발송은 실행하지 않았다. 최종적으로 사용자는 “지원 경로 확보 후 구현 조건 유지”를 선택했다.

## 문의 제목

PC 당근 카페의 내 글·전체 댓글 조회 및 개인 도구 이용 가능 범위 확인

## 문의 본문

안녕하세요. 개인 Windows PC에서 당근 카페를 이용하고 있습니다. 아래 기능의 공식 지원 여부와 허용 범위를 확인 부탁드립니다.

1. PC 웹 `cafe.daangn.com`에서 제가 작성한 글 전체 목록 또는 게시판의 작성자/내 닉네임 필터를 이용할 수 있나요? 지원된다면 정확한 메뉴 순서나 공식 접근 주소를 알려주세요. 예전에 올린 글과 중복해서 게시하지 않기 위해 필요합니다.
2. 로그인한 PC 웹에서도 댓글 전체보기를 누르면 당근 앱 전용 안내가 나옵니다. PC 웹에서 본인 글의 모든 댓글과 답글을 읽는 지원 경로가 있나요? 지원 여부가 글 소유자·카페 권한 등에 따라 달라지는지도 궁금합니다. 현재 화면에 보이는 댓글의 정렬·개수 제한도 알려주실 수 있을까요?
3. 카페 운영정책의 구인구직·서비스 홍보 제한을 확인했습니다. 프리랜서 개발자의 웹사이트/프로그램 개발 서비스 소개 및 작업 문의 안내 글을 올릴 수 있는 허용 조건이 있나요? 카페 운영자의 승인만으로 가능한지, 별도 광고 협업이나 다른 공식 경로를 이용해야 하는지 확인 부탁드립니다.
4. 사용자 본인이 직접 로그인한 전용 Edge 프로필로 개인 PC의 도구가 글을 읽고, 명시적으로 승인한 카페에 서비스 소개 글을 카페당 한 번 게시하며, 본인 글의 댓글을 읽어주는 방식이 허용되나요? 자동 댓글·채팅·가입·인증 우회는 하지 않습니다. 이런 자동화에 사전 서면 동의가 필요하다면 신청 절차와 담당 창구를 알려주세요.

비공개 API를 직접 호출하거나 앱 전용 제한을 우회하는 방식은 사용하지 않으려 합니다. 현재 지원되는 공식 기능과 허용된 방법으로 이용할 수 있도록 안내 부탁드립니다.

## 답변 후 구현 진입 판단

- 내 글 대조·전체 댓글 조회의 실제 지원 경로를 전용 브라우저에서 검증한다. 기능 소개만으로 통과시키지 않는다.
- 서비스 소개 템플릿의 게시 허용 조건과 필요한 동의를 확인한다. 카페별 규칙과 사용자 승인은 별도로 유지한다.
- 두 경로와 게시 허용 근거가 확보되면 원 PRD의 M1→M5를 진행한다. 웹 미지원 답변이면 원 요구 유지 결정에 따라 구현 보류 상태를 유지하고 결과를 보고한다.
- 어떤 경우에도 실제 게시 검증은 사용자가 고른 카페 1곳에서 로컬 검증 이후 한 번만 한다.
