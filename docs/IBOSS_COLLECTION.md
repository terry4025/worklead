# 아이보스 공개 원문 수집

## 탐색 범위

`https://www.i-boss.co.kr/ab-1957?sort=now`의 **모집 중 공개 대행의뢰 전체 분류**를 확인한다. 제목·분류·검색어로 상세 확인 대상을 미리 버리지 않는다. 사이트에 표시된 실제 다음 페이지를 따라 마지막 페이지까지 진행한다. 마감된 과거 의뢰의 전체 보관 수집, 비공개 글, 목록에 없는 글, 로그인·유료 연락처는 포함하지 않는다.

## 처리 순서

1. robots 확인 및 공개 목록 읽기.
2. 공고 ID로 중복을 정리하고 해당 페이지의 URL·다음 페이지·진행 위치를 영속 저장.
3. 신규 의뢰의 공개 본문·예산·게시일·마감을 읽기. 최근 확인한 동일 공고는 캐시를 활용한다.
4. AI 없이 기존 로컬 규칙으로 개발 납품 요청과 지급 단위를 판정. 시급·일급·월급·성과당·지급 방식 미확인, 일반 광고 운영·소재 제작은 검토 대상에서 제외한다. 실제 웹/프로그램 제작 요청은 유지한다.
5. 원격 여부·개발 범위가 불명확하면 확인 필요로 표시한다. 원문에 없는 조건을 추정하지 않는다.
6. 저장된 리드는 기존 제목·본문 검색, 사이트 필터, 관심·메모·영업 기록을 이용한다.

## 마감 판정

- 현재 의뢰의 마감 배지와 의뢰자 정보 안의 `마감된 의뢰입니다` 버튼을 확인한다. 관련 글·광고·본문·숨김 템플릿의 같은 문구를 현재 글 상태로 사용하지 않는다.
- 일자만 있는 마감은 한국시간 해당 날짜 전체를 포함한다. 다음 날부터 저장된 명시 마감일을 근거로 조회 시 마감·자동 제외를 적용하며, 원문을 새로 확인한 것처럼 확인 시각을 바꾸지 않는다.
- 목록·상세·필터·건수는 같은 마감 판정을 사용한다. 앱은 기존 60초 시계에서 한국 날짜 변경을 감지하면 로컬 조회를 갱신하며, 작성 중인 메모·초안·계약 입력을 보존한다.
- 파서 버전이 바뀌면 다음 탐색에서 이전 버전의 상세 캐시를 새 파서 결과로 재확인한다. 요청 유예·일일 예산은 계속 적용한다.

## 요청과 이어보기

- 로컬 기본값: 하루 600요청, 요청 간격 최소 6초, 실행당 120요청, 자동 탐색 3시간.
- 실행당 예산이 끝나면 남은 원문을 버리지 않는다. 저장된 페이지의 다음 원문부터 자동 수집이 켜져 있을 때 1분 뒤 이어간다. 고정 페이지 수로 탐색 범위를 영구 절단하지 않는다.
- 페이지 중간에 중단돼도 당시 발견한 URL을 보존해 목록이 바뀌면서 누락되는 일을 줄인다. 하위 페이지가 남아 있으면 주기 완료로 계산하지 않는다.
- 마감 제외 목록이 줄어 요청 페이지가 마지막 페이지를 넘으면, 알려진 빈 목록 구조와 정상 페이지 이동 영역이 가리키는 마지막 페이지를 함께 확인해야 종료한다. 모양만 빈 응답은 실패로 남긴다. 목록 자체가 크게 바뀌는 경우 다음 전체 순환에서 앞 페이지로 이동한 글을 다시 확인한다.
- 일일 예산·429는 유예하고, 로그인 요구·403·CAPTCHA·robots 금지는 공통 엔진에서 중단한다.
- 위 수치는 앱의 부하 관리 설정이며 사이트의 공식 허용 쿼터가 아니다. 모든 비공개 원문이나 시장 전체의 발견률을 보장하지 않는다.
