# 보수와 검토 우선순위

규칙 `rules-2026.10.12-pay`부터 기존 조건 적합성 항목은 유지하고 보수 감점을 별도로 표시한다. 점수는 수주 확률이나 실제 수익 보장이 아니다.

비교 기준은 기본 소액 검토 기준 10만원과 사용자가 설정한 최소 계약금액 중 큰 금액이다. 목표 시간가치가 있으면 기존 업무별 낙관적 예상 시간 × 목표 시간가치도 비교 기준에 반영한다. 기본 10만원은 제품의 소액 의뢰 선별 기준이며 시장 적정가나 사용자가 입력한 조건으로 표시하지 않는다. 투입 시간은 규칙 추정치다.

확인된 원화 건당 보수의 **상한**이 비교 기준의 25% 미만이면 우선순위 최대 39점, 50% 미만이면 59점, 100% 미만이면 74점으로 제한한다. 기존 점수가 더 낮으면 올리지 않는다. 25% 미만은 조건 적합성을 유지하면서 `확인 필요`로 분류하고 전체 작업 계약금액인지, 범위에 맞게 협의할 수 있는지 질문한다. 기존 제외 조건은 우선한다.

보수 미정·상한 없는 하한 금액·지급 단위 미확인·외화·사이트와 본문 금액 충돌은 확정된 저보수로 단정하지 않고 감점을 보류한다. 넓은 금액 범위는 상한으로 비교한다. 기존 최소 계약금액 확인 조건은 별도로 유지한다. 보수 원문과 사용자 기록은 변경하지 않는다.
