# M0 결과에 따른 구현 경로 (2026-10-12)

이 문서는 사용자 검토용 대안이다. 원본 `CAFE_AUTOMATION_PRD.md`를 변경하거나 아래 변경안을 승인한 것으로 취급하지 않는다. 관찰 근거는 [CAFE_RESEARCH.md](CAFE_RESEARCH.md)에 있다.

**사용자 결정: 경로 A를 선택했다.** “원 요구 유지: 내 글·전체 댓글을 읽을 수 있는 지원 경로를 확보한 뒤 구현.” 경로 B는 적용하지 않는다.

## 경로 A — 원 요구 유지

F3의 기존 내 글 대조, F4의 누락 없는 댓글 조회를 그대로 유지한다. 지원되는 웹 UI에서 내 글·닉네임 필터와 전체 댓글 조회 경로가 확보될 때까지 §9에 따라 구현 진입을 보류한다. 사용자가 알고 있는 실제 화면 경로나 공식 지원 방식이 있으면 그 경로를 읽기 전용으로 검증한다. URL·비공개 API를 추측하거나 앱 전용 제한을 우회하지 않는다.

## 경로 B — 웹에서 확인한 범위로 명시적 변경

승인 시 원본 PRD의 F1~F4 및 완료 기준을 먼저 변경한 뒤 M1→M5 순서로 구현한다.

| 원 요구 | 제안하는 변경과 한계 |
| --- | --- |
| 검색어·지역 화면에서 카페 찾기 | 관찰된 카테고리 목록 탐색, 목록 내 검색어 일치 분류, URL 수동 등록. 서버 검색·독립 지역 필터라고 표시하지 않는다. |
| 내 글 자동 제외 | 사용자가 등록한 내 글 URL을 제외한다. 미등록 과거 글까지 내 글이라고 식별한다는 보장은 제거한다. |
| 최초 게시 전 내 글 자동 대조 | 최초 카페마다 사용자가 기존 글을 직접 확인하고 기존 글 URL 또는 기존 글 없음 확인을 기록한다. 미확인 카페는 게시하지 않는다. DB의 기존 게시 기록·등록한 글은 계속 건너뛴다. 자동 대조 성공으로 표시하지 않는다. |
| 모든 댓글 문의 감시 | 웹에서 노출된 댓글과 확장 가능한 답글만 읽는다. 조회 범위가 불완전함을 문의 화면에 지속 표시하고 당근 앱에서 전체 확인하도록 안내한다. 미표시 댓글·알림 누락 가능성을 완료 기준에 명시한다. |
| 정확한 댓글 작성 시각·답글 관계 | 실제 노출 근거만 저장한다. 상대 시각과 최초 확인 시각을 구분하고, 부모 관계·절대 시각을 추측하지 않는다. |

다음 조건은 두 경로 모두 유지한다: 전용 Edge 프로필, 사용자 직접 로그인·가입, 위험 안내 확인, 기본 자동 게시 꺼짐, 승인된 대상만 게시, 카페당 한 건, 제출 불확실 시 재게시 금지, 고정 간격·일일 예산, 인증/차단 시 정지, 자동 댓글·채팅 금지, 로컬 가짜 카페 검증 우선, 사용자가 고른 카페 1곳에 한 번만 실사이트 게시 검증. 기존 동일 템플릿 글이 발견된 카페는 소유 여부가 해결되기 전 신규 게시 대상으로 사용하지 않는다.

웹 한계를 수용하는 경로 B도 원 요구의 전부를 달성하는 구현이 아니다. 범위 변경 승인 전 제품 코드·DB·설치본을 변경하지 않는다.
