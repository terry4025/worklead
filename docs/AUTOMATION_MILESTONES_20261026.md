# 완전 자동화 운영 준비도와 마일스톤 (2026-10-26)

## 판정

**완전 자동화 운영 완료로 판정할 수 없다.** 공개 수집·분류·자동 지원·자동 지원 재연결의 구현과 설치 검증은 있지만, 실제 Chrome에서 발견→제출 완료→답장 알림이 이어진 증거가 없다. 자동 지원 재연결의 완성과 메시지 감시 재연결의 완성도 구분해야 한다.

목표는 Worklead가 실행되고 로그인·권한이 정상인 동안 전국의 수행 가능한 제작 의뢰를 발견하고, 기존 승인 범위의 50점 이상 공고를 현재 원문·저장 소개·지원 이력과 대조해 자동 지원하는 것이다. 필수 질문·계정 변경·결과 미확인은 이유를 표시하고 중지한다. 로그인·추가 동의·불확실한 제출을 자동으로 넘기는 것은 완료 기준이 아니다.

## 후속 진행: M2 재연결 구현·연결 실패 진단

사용자의 ‘다음 마일스톤 진행·코드 입력 연결 실패 수정’ 요청으로 **메시지 감시의 별도 허가 보존·앱/Chrome 재시작 복구**를 구현했다. 확장 0.5.0은 코드 목적·만료·앱 미실행·권한·로그인·별도 탭 필요를 구분하고 실제 첫 관찰 수락 전에는 성공을 반환하지 않는다. 상세 동작은 [메시지 재연결](MESSAGE_RECONNECT_20261026.md), 최종 검사/설치 상태는 [STATUS](STATUS.md)에 기록한다.

**M1과 M2의 운영 완료 판정은 계속 보류한다.** 실제 Chrome에서 새 버전 재로딩·최초 연결·실제 제출 완료·수신 답장과 Windows 알림의 대조가 남아 있다. M2의 같은 미읽음 합계인 새 메시지 식별 보완도 미완료다. 아래 ‘확인한 사실’과 ‘남은 간극’은 최초 10:38–10:45 검토 스냅샷이며 현재 구현과 구분한다.

## 이번 검토에서 확인한 사실

- 10:38–10:45 KST 운영 DB를 읽기 전용으로 조회했다. 리드 1,593건, 자동 지원 시도 0건, 자동 지원 전용 원문 재확인 작업 0건, 미읽음 증가 알림 기록 0건이다. 알림 기록 0건은 실제로 답장이 없다는 증거가 아니다.
- 당근 자동 수집은 켜져 있고 설정은 5분이다. 최근 실제 탐색 성공과 재확인의 부분 실패(`recheck_errors`)가 있다. 종료/절전 구간이 끼어 있는 작업의 생성→종료 간격을 처리 지연으로 단정하지 않는다.
- 저장 점수 50점 이상·검토 큐 공고 13개를 현재 `condition(..., queue=True)`로 읽기 전용 재평가하면 기본 큐 후보 6개, 조건 불일치 7개다. 6개 중 5개는 원문 확인 TTL이 지났으며, 나머지 1개도 현재 지원 양식·기지원 여부 대조가 필요하다. 현재 제출 가능 공고 6건으로 해석하지 않는다.
- 설치 백엔드는 빌드 파일과 일치하고, 준비된 확장 0.4.0의 12개 파일도 저장소와 일치한다. Chrome에 실제 로드된 버전과 연결 상태까지 확인한 결과는 아니다.
- 기존 최종 검사 기록은 전체 백엔드 1,278 통과·선택 검사 2개 제외, 최종 변경 집중 140개 통과, UI 320개·확장 52개 통과다. 이번 검토에서 전체 검사를 다시 실행하지 않았다.
- 현재 Worklead 창은 읽었지만 지원 화면으로의 전환은 Windows 입력 도구의 `coordinate input geometry is unavailable` 오류로 확인하지 못했다. 시작·중지·연결키·Chrome·지원 제출 설정은 변경하지 않았다.

M1 개통 확인을 먼저 진행한다. 최초 Chrome 설치/권한·로그인에 사용자 조작이 필요한 동안에도 M2/M3의 독립적인 구현·검사는 진행할 수 있다. Chrome 보안 관리 화면은 앞서 도구가 차단한 영역이며 레지스트리·프로필·권한 정책으로 대신 설정하지 않는다.

속도의 초기 목표는 **원문이 신선하고 추가 질문이 없는 신규 적격 공고의 발견→지원 처리 결과 p95 60초 이내**로 잡고, 실제 사이트의 응답 지연과 요청 대기 구간을 함께 기록해 조정한다. 게시→발견 지연은 지역별로 따로 측정한다. 전국 모든 공고에서 경쟁자보다 먼저 지원한다고 보장하지 않는다.

운영 완료 이후에도 지원 완료·고용주 열람·답장·협의·계약·수금은 각각 별도 지표다. 점수는 채택 확률이 아니며 자동 지원 성공을 수익 발생으로 계산하지 않는다.
