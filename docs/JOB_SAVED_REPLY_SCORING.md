# 저장 공고 자동 지원·보이는 채팅·적합도 점수 (2026-10-25)

사용자는 이미 발견한 미지원 공고의 자동 지원, Worklead 내 답장 확인, 제작 의뢰 점수 개선을 요청했다. 50점·하루 기본 20건·저장된 당근 기본 자기소개를 유지한다. 실제 지원·채택·계약·수금은 각각 별도 증거다.

## 저장된 공고

최근 24시간 제한을 제거했다. 신규 공고부터 기존 저장 공고로 진행하며 한 번에 하나를 처리한다. 게시·발견 시각은 고치지 않는다. 저장 점수·현재 규칙·제작 구매 의도·건당 지급·모집 상태·소스 허용·접근 가능·미연락·미제외를 대조한다.

모집 확인 TTL이 지난 글은 우선 `recheck_stale` 수집 작업으로 원문·보수·모집 상태를 다시 확인한다. 분당 최대 한 건을 준비하고 같은 리드/시간대의 큐를 중복 만들지 않는다. 수집기 하나에서 기존 요청 예산·발견용 예산 예약·실패 backoff를 지킨다. 재확인이 끝난 뒤 같은 공고 ID·제목·계정의 기본 자기소개 양식이 실제로 열렸다는 `application_form` 증거도 확인한다. 양식이 열려 있다는 이유로 오래된 본문/보수 정보를 최신으로 간주하지 않는다. 그 관찰은 현재 연결의 receipt/lease에만 묶으며 과거 게시 시각을 최신으로 바꾸지 않는다. 옛 확장은 오래된 글을 제출할 수 없다. 최종 허가 직전에도 조건을 다시 확인한다. 날짜 미확인·접근 불가·명시 마감은 계속 보류/제외한다.

지원 취소 표시가 있으면 기존 지원으로 기록한다. 이미 시도한 보류·결과 미확인·제출·기존 지원 및 외부 journal 기록은 다시 제출하지 않는다. 단순히 Worklead에 성공 기록이 없다는 이유로 반복 클릭하지 않는다.

## Worklead에서 채팅 보기

Worklead의 현재 크롬 연결과 확장 팝업 양쪽에서 ‘보이는 채팅 내용’을 켠 뒤 메시지 전용 탭을 연결한다. 확장 0.3.0은 11개 파일이다. 자동 지원 탭과 별도로 사용한다. 연결 동작은 채팅 **목록**만 한 번 열 수 있고, 개별 대화 선택·전송·입력·삭제를 수행하지 않는다.

선택한 탭의 `role=dialog`, `aria-label=채팅` 영역에서 렌더링된 텍스트만 읽는다. textarea/input/contenteditable·버튼·스크립트·다른 본문은 제외한다. 최대 4,000자로 앞·뒤를 표시하며 이미지·숨겨진 대화·가상 스크롤 밖 기록은 읽지 않는다. 자세한 답장은 사용자가 크롬에서 대화를 선택하면 Worklead에도 표시된다. 현재 DOM 선택자는 과거 공개 번들의 구조와 합성 DOM을 근거로 하며 실계정 최신 화면 일치는 미검증이다.

2초 주기와 DOM 변경 감지로 로컬에 전달하고 Worklead는 2초마다 자동 반영한다. 미읽음 증가 알림은 기존 앱/Windows 알림을 쓴다. 같은 미읽음 수에서 텍스트가 달라져도 표시 내용은 갱신하지만, 모든 새 답장을 빠짐없이 알리는 스트림은 아니다. 배경 탭·절전·사이트 UI 변경으로 지연될 수 있다.

공고 링크가 하나로 확인되는 경우만 저장 리드와 연결한다. 연결 공고가 없으면 특정 지원의 답장으로 단정하지 않는다. 보이는 내용에는 본인이 보낸 메시지도 포함될 수 있다. 자동 회신은 없다.

본문은 실행 메모리에만 있으며 SQLite·파일·알림 본문·AI로 보내지 않는다. 로컬 API에는 인증과 `no-store`, 확장 브리지에는 별도 키·정확한 Origin/Host·선택한 최상위 탭·크기/순서 검증을 적용한다. 기존 미읽음 `/observe`는 여전히 512바이트의 엄격한 숫자 전용이고, `/chat`만 별도 활성화해 최대 25KB를 받는다. 정지·재시작·복원·로그인 변경 시 지우고 15초 관찰이 끊기면 내용을 숨긴다.

## 점수

업무 35·구매 의도 30·원격 10·최신성 15·범위 명확성 10이다. 원격 미확인은 점수를 지어내지 않고 `null`로 남긴다. 납품 적합도와 명시 구매 수요가 전체 점수에서 더 큰 비중을 갖고, 명시 지속 의뢰는 단발 의뢰와 같은 구매 강도로 평가한다. 서비스 미설정은 기술 보유 확인이 아니며 화면에 미설정 근거를 표시한다. 사용자가 명시적으로 제공하지 않는 서비스는 기존 낮은 적합도를 유지한다.

소프트웨어 대상과 수리/복구/배포/연동 요청이 연결된 표현, 어플리케이션 제작을 보완했다. 물리 작업·채용·홍보·교육·조언·위험·시급 보수 제외와 낮은 예산 감점은 유지한다. 홈페이지 제작을 ‘배우고 싶다’는 실제 저장 사례는 교육으로 제외했다. 규칙은 `rules-2026.10.25-fit2`다.

당근 어댑터 0.8.2는 검색어 ‘앱’에서 ‘어플/어플리케이션/애플리케이션’ 개발 표기를 함께 비교한다. 다른 검색어의 범위를 무시하지 않으며 설치·포인트 글을 제작 핵심 후보로 올리지 않는다. 이를 전국 모든 공고를 가져온 증거로 해석하지 않는다.

실제 저장된 당근 리드 1,182건을 동일 시각·설정으로 전후 재생했다. 적격 검토 18→17, 제외 1,164→1,165로 교육 오탐 1건을 제거했다. 스프레드시트 60→70, 홈페이지 리뉴얼 56→66, 웹 앱 66→76 등이다. 원문 상태가 마감인 사례도 재생 표본에 들어 있으므로 점수 변경을 신규 영업 기회·실제 지원으로 계산하지 않는다. 저장 큐 조건을 통과한 6건도 실제 현재 양식과 제출 결과는 별도 확인해야 한다.
